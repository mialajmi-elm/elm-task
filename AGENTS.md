# elm-tasks

Small local full-stack coding-agent demo. Keep changes easy to read and explain.

## Run and test

- Requires Node 22.13+ (Node 24 recommended). The Node 22 SQLite warning is expected.
- `npm ci` installs the locked dependencies.
- `npm run seed` adds sample data only when the database is empty.
- `npm run dev` serves the frontend and API at http://127.0.0.1:3000.
- `npm test` runs unit, database, and Fetch API handler tests.
- `npx playwright install chromium` installs the browser once.
- `npm run test:e2e` builds the app and runs real-browser tests against an isolated production server on port 3100.
- `npm run test:all` runs both suites and TypeScript checks. Never use the demo database in tests.

## Architecture

- `src/routes/index.tsx`: React UI using TanStack Query for fetching and mutations.
- `src/routes/api.*.ts`: TanStack Start server routes.
- `src/server/api.js`: Fetch request/response handlers, validation, and error responses.
- `src/server/*.server.js`: server-only SQLite connection. Never import into client components.
- `src/view.js`: pure filtering and summary logic.
- `src/validation.js`: request validation and title normalization.
- `src/database.js`: SQLite schema and prepared statements.
- `scripts/serve.js`: production adapter (`npm run build` then `npm start`).
- `src/routeTree.gen.ts`: generated by TanStack; do not edit manually.
- `tests/`: Node test runner. `tests/e2e/`: Playwright.

## Conventions

- API success envelopes: `{tasks: [...]}` or `{task: {...}}`. Errors: `{error: "message"}`.
- Titles must contain non-whitespace text and be at most 120 characters after trimming.
- `completed` is a JSON boolean. Reject unknown fields and empty patches.
- Render user text with React escaped text nodes. Use parameterized SQL.
- Test externally observable behavior and failures. Keep API and database rules consistent.
- Schema changes must support existing SQLite files, not just new databases.
- Keep all baseline tests passing. Do not implement tasks from DEMO.md unless asked.
